# Academia IA - Aplicación Educativa Interactiva 🧠✨

## 📚 Descripción General

**Academia IA** es una plataforma educativa web interactiva diseñada para estudiantes de **8º básico hasta 3º de bachillerato**. La aplicación enseña **Inteligencia Artificial** de forma progresiva, vistosa e interactiva, cubriendo desde conceptos fundamentales hasta aplicaciones reales.

## 🎯 Objetivo

Hacer que el aprendizaje de IA sea accesible, divertido y comprensible para estudiantes sin experiencia técnica previa.

---

## 📖 Contenido Académico Completo

### **Unidad 2: Fundamentos de la Inteligencia Artificial**
- ✅ ¿Qué es la Inteligencia Artificial?
- ✅ Evolución de la IA (1950s → 2020s)
- ✅ Tipos de IA (Débil, Fuerte, Super)

### **Unidad 3: Algoritmos y Lógica**
- ✅ ¿Qué es un Algoritmo?
- ✅ Lógica y Condicionales (SI-ENTONCES)

### **Unidad 4: Aprendizaje Automático (Machine Learning)**
- ✅ ¿Qué es Machine Learning?
- ✅ Tipos de Aprendizaje (Supervisado, No Supervisado, Refuerzo)

### **Unidad 5: Redes Neuronales**
- ✅ Introducción a Redes Neuronales
- ✅ Deep Learning (Aprendizaje Profundo)

### **Unidad 6: Aplicaciones de IA en el Mundo Real**
- ✅ IA en la vida cotidiana
- ✅ Ética y Responsabilidad en IA
- ✅ Futuro de la IA y oportunidades

## 📖 Cómo Usar

1. **Descarga los archivos** en la misma carpeta
2. **Abre index.html** en tu navegador
3. **Selecciona una Unidad** (2-6)
4. **Lee → Ejemplo → Ejercicio**
5. **Verifica tu respuesta**

## 🔧 Personalización

### Cambiar Colores
Edita `styles.css`:
```css
:root {
    --primary-red: #FF6B6B;      /* Tu color aquí */
    --primary-blue: #4ECDC4;
    --primary-yellow: #FFE66D;
    --primary-orange: #FF8C42;
    --primary-purple: #95E1D3;
}
```
